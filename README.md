# Proyecto 3: Katas Python

Este repositorio contiene la resolución de las katas correspondientes al Proyecto 3.

## Contenido

- 📘 Katas de Python resueltas en un notebook de Jupyter (`.ipynb`).

## Nota sobre el formato de entrega

Durante el desarrollo del módulo de Python se ha trabajado utilizando **Jupyter Notebook**, ya que fue el entorno empleado a lo largo del curso para realizar los ejercicios y las prácticas.

Por este motivo, las katas se entregan en formato **`.ipynb`**, conservando:

- Los enunciados de los ejercicios.
- El código desarrollado.
- La ejecución y el resultado de cada ejercicio.

Considero que este formato facilita la lectura, la revisión y la ejecución del proyecto, manteniendo la misma estructura utilizada durante todo el proceso de aprendizaje.

## Tecnologías utilizadas

- Python 3
- Jupyter Notebook
